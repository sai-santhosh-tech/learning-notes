Invoice Generation using Spring Batch in Spring Boot


“I worked on an Invoice Generation Batch application using Spring Boot, Spring Batch, RabbitMQ, and AWS S3.

The overall flow works in multiple stages for better scalability and asynchronous processing.

1) First, the Spring Batch Reader fetches eligible invoice records from the Invoice database in chunks.
2) After reading the records, instead of processing everything synchronously, we publish the invoice data/events to RabbitMQ.
   We used RabbitMQ as a message broker to decouple the batch reading process from invoice processing, which improved scalability and fault tolerance.
3) On the consumer side, we implemented a RabbitListener that listens to the queue asynchronously.
   The listener processes each invoice record, performs the required business validations/calculations, and persists the processed invoice details into the database.
4) Once the invoice data is successfully stored, we generate the invoice document (PDF/file generation logic) and upload the generated invoice file to AWS S3 for storage and retrieval.
5) We also handled retry/error scenarios to ensure failed messages can be reprocessed without impacting the entire batch execution.

This design helped us improve performance, avoid long-running synchronous processing, and support high-volume invoice generation efficiently.”



High-Level Flow =>

DB Records
    ↓
Spring Batch Reader
    ↓
Processor
    ↓
RabbitMQ Producer
    ↓
Rabbit Queue
    ↓
RabbitListener Consumer
    ↓
Process + Save DB
    ↓
Generate Invoice PDF
    ↓
Upload to AWS S3




// ============================
// 1. Spring Batch Job Config
// ============================

@Configuration
@EnableBatchProcessing
public class InvoiceBatchConfig {

    @Autowired
    private InvoiceReader invoiceReader;

    @Autowired
    private InvoiceProcessor invoiceProcessor;

    @Autowired
    private InvoiceWriter invoiceWriter;

    @Bean
    public Step invoiceStep(JobRepository jobRepository,
                            PlatformTransactionManager transactionManager) {

        return new StepBuilder("invoiceStep", jobRepository)
                .<InvoiceEntity, InvoiceMessage>chunk(100, transactionManager)
                .reader(invoiceReader)
                .processor(invoiceProcessor)
                .writer(invoiceWriter)
                .build();
    }

    @Bean
    public Job invoiceJob(JobRepository jobRepository,
                          Step invoiceStep) {

        return new JobBuilder("invoiceJob", jobRepository)
                .start(invoiceStep)
                .build();
    }
}


// ============================
// 2. Reader - Read from DB
// ============================

@Component
public class InvoiceReader extends JpaPagingItemReader<InvoiceEntity> {

    public InvoiceReader(EntityManagerFactory emf) {

        setEntityManagerFactory(emf);

        setQueryString(
            "SELECT i FROM InvoiceEntity i WHERE i.status='PENDING'"
        );

        setPageSize(100);
    }
}


// ============================
// 3. Processor - Convert Message
// ============================

@Component
public class InvoiceProcessor
        implements ItemProcessor<InvoiceEntity, InvoiceMessage> {

    @Override
    public InvoiceMessage process(InvoiceEntity item) {

        InvoiceMessage message = new InvoiceMessage();

        message.setInvoiceId(item.getId());
        message.setCustomerName(item.getCustomerName());
        message.setAmount(item.getAmount());

        return message;
    }
}


// ============================
// 4. Writer - Send to RabbitMQ
// ============================

@Component
public class InvoiceWriter
        implements ItemWriter<InvoiceMessage> {

    @Autowired
    private RabbitTemplate rabbitTemplate;

    @Override
    public void write(Chunk<? extends InvoiceMessage> items) {

        for (InvoiceMessage msg : items) {

            rabbitTemplate.convertAndSend(
                    "invoice.exchange",
                    "invoice.routing.key",
                    msg
            );
        }
    }
}


// ============================
// 5. RabbitMQ Configuration
// ============================

@Configuration
public class RabbitMQConfig {

    @Bean
    public Queue invoiceQueue() {
        return new Queue("invoice.queue");
    }

    @Bean
    public TopicExchange exchange() {
        return new TopicExchange("invoice.exchange");
    }

    @Bean
    public Binding binding() {

        return BindingBuilder
                .bind(invoiceQueue())
                .to(exchange())
                .with("invoice.routing.key");
    }
}


// ============================
// 6. Rabbit Listener Consumer
// ============================

@Component
public class InvoiceConsumer {

    @Autowired
    private InvoiceService invoiceService;

    @RabbitListener(queues = "invoice.queue")
    public void consume(InvoiceMessage message) {

        // Process invoice
        invoiceService.processInvoice(message);
    }
}


// ============================
// 7. Service Layer
// ============================

@Service
public class InvoiceService {

    @Autowired
    private InvoiceRepository invoiceRepository;

    @Autowired
    private S3Service s3Service;

    public void processInvoice(InvoiceMessage message) {

        // Save processed invoice
        ProcessedInvoice invoice = new ProcessedInvoice();

// ============================
// 8. AWS S3 Upload
// ============================

@Service
public class S3Service {

    @Autowired
    private AmazonS3 amazonS3;

    public void upload(String fileName, byte[] data) {

        ObjectMetadata metadata = new ObjectMetadata();

        metadata.setContentLength(data.length);

        amazonS3.putObject(
                "invoice-bucket",
                fileName,
                new ByteArrayInputStream(data),
                metadata
        );
    }
}


“In our Invoice Generation Batch, we implemented fault tolerance to ensure that failures in processing individual invoices do not stop the entire batch execution.

For example:

If one invoice fails during PDF generation,
Or S3 upload fails temporarily,
Or DB save throws an exception,

the system can retry or skip that specific record while continuing to process the remaining invoices.

We achieved this using Spring Batch fault-tolerant features along with RabbitMQ retry mechanisms.”


1. Retry Mechanism

If S3 upload fails due to temporary network issue:

.faultTolerant()
.retry(S3Exception.class)
.retryLimit(3)

Meaning:

Retry same invoice 3 times before marking it failed.



2. RabbitMQ Reliability

RabbitMQ helps fault tolerance because:

Messages remain in queue until consumed
Failed consumers can reprocess messages
Avoids data loss during app restart/crash


3. Dead Letter Queue (DLQ)

If invoice processing fails multiple times:

Message moves to DLQ
Team can analyze failed invoices separately
